# Tresata

> Tresata is a Charlotte, North Carolina enterprise software company building what it
> describes as the foundational data layer for agentic AI. Its platform automates data
> accuracy, entity resolution and enrichment across AWS, Azure and Google Cloud through
> a low-code interface, and is priced by usage in Tresata Transaction Units (TTUs).

IMPORTANT FOR AGENTS: Tresata publishes no public API. There is no developer portal, no
API reference, no OpenAPI/Swagger, no GraphQL SDL, no AsyncAPI, no gRPC/protobuf, no
WSDL, no MCP server and no A2A agent card on any Tresata host, as of 2026-08-30. The
product is reached only by signing in to a tenant application. Do not attempt to call a
Tresata API; there is nothing to call. This file is generated by API Evangelist from
public sources — it is not published by Tresata.

## Open source

Tresata publishes first-party open-source JVM data-engineering libraries under the
`com.tresata` group on Maven Central. These are general-purpose Spark/Cascading/Kafka
libraries — they are NOT SDKs for a Tresata API.

- [spark-datasetops](https://github.com/tresata/spark-datasetops) 1.6.0 (2024-01-05)
- [spark-sorted](https://github.com/tresata/spark-sorted) 2.5.0 (2023-07-03)
- [akka-http-spnego](https://github.com/tresata/akka-http-spnego) 0.5.0 (2020-01-19)
- [spark-kafka](https://github.com/tresata/spark-kafka) 0.9.0 (2017-07-14)
- [spark-skewjoin](https://github.com/tresata/spark-skewjoin) 0.5.0 (2017-07-14)
